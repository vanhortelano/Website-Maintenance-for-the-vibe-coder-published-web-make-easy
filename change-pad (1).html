Change Pad

Compare your original project with the revised one. Change Pad lists exactly what changed, file by file and line by line, so you can edit only those places in your live repository instead of deleting and re-uploading everything.

Load both sides to compare.

Removed text and Replaced text show only the lines that changed, with their line numbers. Files deleted completely appear under Removed files. Folders and bundles are matched by file path, and a shared top folder name is ignored, so site/ and site-v2/ still line up.
